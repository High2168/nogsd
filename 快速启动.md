# 就业推荐系统 - 快速启动指南

## 环境要求

- Python 3.10+
- Node.js 18+

## 一键启动

### 1. 启动后端

双击运行 `backend/start.bat`

或手动执行:
```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

后端地址: http://localhost:8000
管理后台: http://localhost:8000/admin

### 2. 导入数据

双击运行 `backend/import_data.bat`

或手动执行:
```bash
cd backend
venv\Scripts\activate
python manage.py shell
>>> from apps.data.import_data import import_data
>>> import_data(r"C:\Users\qingd\Downloads\data job posts.csv\data job posts.csv", limit=2000)
```

### 3. 启动前端

双击运行 `frontend/start.bat`

或手动执行:
```bash
cd frontend
npm install
npm run dev
```

前端地址: http://localhost:3000
